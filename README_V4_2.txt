ระบบบริหารทรัพย์สินสาขา V4.2
ปรับประสิทธิภาพ + ปรับอัปโหลดรูปทรัพย์สิน

สิ่งที่ปรับปรุง
1) ความเร็ว
- ลดการอ่าน Google Sheet ซ้ำตอน Login
- Cache รายชื่อสาขา/ชื่อสาขา และตัวเลือกประเภท/ผู้ดูแลชั่วคราว
- อ่านทะเบียนหลักด้วย getValues ครั้งเดียว แทนการอ่าน Values + DisplayValues เต็มชีต
- ค้นหารหัสทรัพย์สินเฉพาะแถวด้วย TextFinder ไม่โหลดทะเบียนทั้งหมด
- บันทึกข้อมูลทรัพย์สินแบบเขียนทั้งแถวครั้งเดียว ลด setValue หลายครั้ง
- หน้ารายงานอ่านทะเบียน/ผลตรวจซ้ำน้อยลง
- ไลบรารี QR จะโหลดเมื่อใช้งานจริง ไม่หน่วงหน้า Login/Dashboard
- บีบอัดรูปบนอุปกรณ์ก่อนส่งขึ้น Apps Script
- รูปทรัพย์สินและใบเสร็จประมวลผลพร้อมกัน
- หลังทะเบียนบันทึกสำเร็จ หน้าเว็บจะกลับมาใช้งานได้ทันที ส่วน QR/PDF สร้างต่ออัตโนมัติโดยไม่บล็อกหน้าจอ

2) รูปทรัพย์สิน / ใบเสร็จ
- มีปุ่ม "ถ่ายภาพ" เปิดกล้องของโทรศัพท์/iPad
- มีปุ่ม "เลือกไฟล์ PNG/JPG" จากเครื่อง
- ถ้าเลือกหลายครั้ง ระบบใช้ไฟล์ล่าสุดและล้างตัวเลือกก่อนหน้า
- แสดงชื่อไฟล์ ขนาดไฟล์ และ Preview ก่อนบันทึก
- รูปจากกล้องจะถูกแปลงเป็น JPG และย่อขนาดก่อนอัปโหลดเพื่อให้เร็วขึ้น
- ไฟล์ที่เลือกจากเครื่องรองรับ PNG/JPG

วิธีอัปเดตจาก V4.1
1. นำ Code.gs และ Index.html V4.2 ไปแทนของเดิม
2. กด Save
3. รัน validateAssetSetup() เพื่อตรวจระบบ (ไม่จำเป็นต้องรัน upgradeAssetSystemV2 เพราะไม่มีคอลัมน์ใหม่)
4. Deploy > Manage deployments > Edit > New version > Deploy
5. ปิดหน้า Web App เดิมแล้วเปิดใหม่

หมายเหตุ
- ครั้งแรกหลัง Deploy อาจช้ากว่าปกติเล็กน้อยเพราะ Cache ยังไม่ถูกสร้าง หลังจากนั้นการ Login/โหลดตัวเลือกสาขาจะเร็วขึ้น
- การสร้าง PDF ยังเป็นงานที่ใช้เวลา แต่ V4.2 ไม่บล็อกหน้าจอรอ PDF หลังบันทึกทะเบียนแล้ว
